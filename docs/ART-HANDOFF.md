# 出图交接说明（给并行出图的 agent）

主数据在 `content/`，构建产物在 `data/`。**你只负责出图并把图放进 `content/art/`，不改任何 `content/*.json`、`content/*.md`、`tools/*.mjs`、`data/` 下的文件。**

## 你要做的

工作清单每行给出：角色名、ID、资产 kind、出图尺寸、prompt 文件、目标路径。

1. **读 prompt 文件**：`data/characters/<ID>/art/<kind>.prompt.md`，取里面 \`\`\` 围栏中的整段文本，**原样**作为 ImageGen 的 prompt。不要自己改写、缩写、翻译——那段文本里已经含全套画风法与该角色的识别项，改一个字就会让这张图和其余 80 张不是一套。
2. **ImageGen**：`name` 用 `<角色名>-<资产中文名>`（如 `虞清都-全身立绘`），`size` 用清单给的尺寸。
3. **自检**：把生成的 PNG 用 Read 看一遍，按下面的验收清单判。不合格就改 prompt 里对应那一条再重出，**同一张最多试 3 次**；3 次仍不合格就跳过并在报告里写明原因，不要硬塞。
4. **落档**：合格的图用 node 复制过去，一次一张：
   `node -e "require('fs').copyFileSync('vibe_images/<生成文件名>.png','content/art/<角色名>-<ID>/<中文名>.png')"`
   目标目录已存在（按角色名命名），不要新建别的目录名。
5. **不要跑** `npm run build` / `node tools/validate.mjs` / `node tools/art-jobs.mjs --mark`：这些会写共享文件（`data/`、`content/art/ledger.json`），并行跑会互相覆盖。台账由主 agent 统一记。

## 验收清单（每张都过一遍）

- **画风**：国风精致厚涂、通透发光的皮肤、一根根画出的发丝、强逆光在轮廓上烧出亮边、体积光与雾感、小件（珠帘/水珠/金属/霜粒）有闪烁高光。**不合格**：硬边平涂赛璐璐、纸片剪影式扁平插画、速涂干笔飞白、灰蒙土黄低饱和、真人照片质感、3D 塑料皮肤。
- **人物是主体**：半身图取腰上近景且占画面高度 75% 以上；全身图必须含头部到双足且人物占高 85% 以上。**不合格**：很远一个小人站在大风景里。
- **识别项照画**：发型发色、瞳色眼形、表情、辨识记号、主道具五项都在。**不合格**：换成通用美人脸。
- **背景是实景**：该角色身份场景的三层景深 + 一个明确时间光，不是纯色渐变。
- **服装与配色**：主色＝该角色六气色（prompt 里给了 hex），辅色＝prompt 里给的辅色，两者都要看得出。
- **非人特征**：兽耳/尾/翅/角/鳃痕要清楚，**数量严格按 prompt 文本里的数字**（狐尾写七条就七条，不许画成九条）。
- **内容安全（硬约束，优先级最高）**：`age_band` 为 child/teen 的角色必须看得出下半身是长裤或及踝长裙、腿部不裸露、平底布鞋、无深胸开口、无透视湿身、无媚态；只有 adult 允许成熟剪裁，且不得裸露与性暗示姿势。低龄角色一旦露腿、高跟、湿身，直接判不合格重出。
- **无**文字、水印、边框、LOGO、UI 元素、卡牌边框。

## 报告格式

完成后回一张表：`角色名 kind 落档路径 结论（ok / 跳过+原因）`，并说明哪些张你不确定、需要人眼复核。不要总结画风，也不要改代码。

## 新增两个资产位：抠图立绘 / 动态立绘（2026-10-24）

| kind | 中文名 | 尺寸 | 用途 |
|---|---|---|---|
| `standee` | 抠图立绘 | 1024x1536 | 立绘舞台主体、战斗出场、剧情叠图；**透明底** |
| `dynamic` | 动态立绘 | 1024x1536 | 同一角色的出招/登场姿态，点立绘时交叉淡入；**透明底** |

- **prompt 里已经写好灰底要求**：`背景＝中性浅灰无缝纯色（约 #9AA0A6）`，并且明确作废"背景必须是实景"那条。不要自己加背景、不要加地面阴影——抠图靠的就是这层纯灰。
- **出图只到"灰底原图"为止**：落 `.raw-art/<角色名>-<ID>/抠图立绘.png`（或 `动态立绘.png`），**不要自己抠**。
  统一由主会话跑 `python tools/finalize-cuts.py` 抠成透明底写回 `content/art/`，这样 81 张的边缘处理才是同一种。
- **自检**：`python tools/qc-one.py <图片>`，要求 `ok:true`（四角底色 std<9 且人物占高≥72%）。不合格用**同一份 prompt 原文**重出，最多 3 次，不许改 prompt 去"修"。
- **为什么不能拿现成的全身立绘直接抠**：实景厚涂的雾光/逆光让显著性分割在 20+ 个角色上抠不准（实测 81 张里 23 张边缘不可用），
  所以改成"抠图专用 prompt 出一张灰底图 → 本地 u2net 抠"。人物识别项与全身立绘同一份数据，不会换人。
- **图生图不可用**：本机 ImageGen 带参考图会返回 `400 no models available`，只能用纯文字 prompt。别试。
